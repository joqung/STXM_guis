Hello, these are a collection of some Python scripts written using Opus 5.5 within Claude AI. These are still works in progress, but they appear to be usable for most data that I have personally worked up. Please let me know if there are any improvements or bugs I can fix.

1. gedgfit: An interactive program for the fitting of STXM light atom XAS data
2. STXMNorm: An interactive program for the normalization of STXM XAS data.
3. STXM_aXis2000 converter: An executable that opens an interactive program for converting CLS SM 10ID-1 and ALS 5.3.2.2 raw data to a format readable by aXis2000
